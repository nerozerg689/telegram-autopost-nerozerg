# Сборка APK (без установки Android Studio)

1. Создайте на github.com пустой **приватный** репозиторий.
2. Загрузите в него содержимое папки `android` (кнопка Add file -> Upload files; папка `.github` тоже должна попасть).
3. Вкладка **Actions** -> «Build APK» -> Run workflow (или сборка стартует сама после загрузки).
4. Через 3-5 минут откройте завершённый запуск, внизу раздел Artifacts -> `incidents-apk`. Скачайте, распакуйте, получите `app-release.apk`.
5. Перекиньте APK на телефон, разрешите установку из неизвестных источников, установите.
6. При первом запуске введите адрес сервера, например `http://192.168.1.50:8000`, и войдите под своим именем.

Либо откройте папку `android` в Android Studio и выполните Build -> Build APK.

## Как работают уведомления
Приложение держит фоновую службу (в шторке висит тихая иконка «Ожидание уведомлений») и опрашивает сервер.
Приходят уведомления: новый инцидент, комментарий, инцидент устранён (свои действия не показываются).
Нажатие открывает нужный инцидент. После перезагрузки телефона служба запускается сама.
На некоторых телефонах (Xiaomi, Huawei, Samsung) нужно отключить оптимизацию батареи для приложения, иначе система её закроет.
Работает без Google и Firebase, поэтому подходит для РФ. Уведомления приходят, пока телефон видит сервер (Wi-Fi завода или VPN).

## Исправление ошибки 401 при подключении
В предыдущей версии Android-приложения проверка соединения обращалась к защищённому `/api/meta` до входа и получала 401. Теперь используется публичный `/login`. Для исправления требуется **собрать и установить новый APK** из папки `android`. Обновление только `server.py` проблему в старом APK не исправит.
